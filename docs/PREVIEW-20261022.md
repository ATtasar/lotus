# 2026-10-22 电脑端空白预览

本文件记录 2026-10-22 的独立空白预览方式。这些功能纳入 1.4.0；正式用户数据不与预览数据库混用。

预览地址：`http://127.0.0.1:17875/#templates`。

预览数据独立保存在源码的 `artifacts/preview-workspace-20261022/`。不要用它替换正式数据目录 `E:\Lotus-v1.1.0`。预览首次使用时订单、单主、平台、图片、事件、健康记录、食物和待办全部为空。24h、48h 及功能类型名称是用户指定的功能入口，不是示例业务记录。

## 特殊稿件

- 模板页最前面提供 24h 和 48h，颜色分别设置。
- 稿件名称由用户填写；单主、类别及平台可留空。
- 从确认保存的时刻起计算 24/48 小时，保存到毫秒；界面显示日期及小时、分钟。日历色条显示时分。
- 编辑特殊稿件可以补充资料及具体时间。日历拖动也会同步修改原稿件。
- 默认颜色为中性灰色。不会自动创建平台、单主、类别或订单。

## 作品展示

风琴本包含封面、图片内页和末尾空白页。当前页占据主要空间，最后一页保持展开。支持批量上传、拖入图片、按加入顺序查看、多选删除、建立/改名文件夹，以及移动图片。删除文件夹时把内容移到上层，不顺带删除图片。

## 生活工具

- 注意事件：独立事件月历、快捷新增、完整列表、可选起止时间、类别新增、内容和备注、完成及删除。无时间事件显示在快捷条下方；有时间事件同步至主页和稿件月历，但不计入稿件收入。
- 生活健康：由用户选择喝水、运动、清洁，或新建自定义组件。图标支持上传；每天用加减记录数量，最近七天图表显示各组件的独立刻度。
- 食物转盘：外卖、菜式分别填写内容。转盘没有指针，中心按钮抽取，结果通过上下滚动的老虎机区域展示。内容可评分、修改描述/备注或删除。
- todolist：用户自行填写，支持编辑、删除和勾选完成。

## 排期

新建普通稿件的开始、截止日期控件可查看已存在排期的颜色提示；提示沿用主页的截止/连续色条模式。截止模式拖动仅改截止日期；连续模式的“起”端整体平移、保留工期，“止”端仅改变截止。若产生开始晚于截止的情况，取消操作并提示。

## 数据兼容

新增记录复用原 SQLite 表和事务接口，关系由外键维护，图片仍存入独立 `data/files`。格式升级至 5，升级前创建完整备份，失败回滚。不在启动时补写用户业务内容。旧版 2/3/4 数据及备份仍可读取；新图片、作品文件夹、健康记录等也进入备份和恢复范围。
