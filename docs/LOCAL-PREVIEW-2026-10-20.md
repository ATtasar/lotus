# 2026-10-20 电脑端本地预览

本文是此前本地预览阶段的历史记录。这些功能已纳入 1.3.0 发布源码，正式下载及升级说明以根目录 RELEASE-NOTES.md 和 START-HERE-WINDOWS.md 为准。

本次按用户要求，只修改本机源码并运行预览。没有提交、推送、发布 GitHub，也没有替换现有安装程序。

## 查看

预览地址：`http://127.0.0.1:17871/#orders`。

这是独立的空白预览工作区。按用户后续要求，演示稿件、单主、平台、模板、素材、价目表和快捷回复已备份后清空，所有功能保留，信息由用户自行添加。应用启动不会填充示例，也不会覆盖现有数据库。`tools/preview_seed.py` 仅用于隔离的演示/测试目录，在数据库已存在时拒绝覆盖；日常启动不调用该脚本。

本机预览数据：`artifacts/preview-20261020/data/workbench.sqlite`，图片：同目录下 `files/`。正式 `%LOCALAPPDATA%\Lotus-Workbench` 数据和原快捷方式未修改。

## 变更规则

- 主页本周排期和月历均可选择“仅显示截止日”或“开始至截止日连续色条”。开始、截止两天都包含在周期内；跨周换行延续，重叠稿件分行。两处共用同一选择，通过现有 SQLite 元数据持久保存；旧数据默认仅显示截止日。平台筛选、日期详情和稿件点击联动继续有效，收入仍按截稿月份统计，不随显示样式改变。
- 收入按**截稿月份**归集，使用订单总额（定金、尾款和额外服务，未扣平台费）。实际收入只计“完成”状态；预测收入计月内全部订单，包含退单。两项总额同时展示，下方平台、类别和单主图表可切换收入类型。
- 稿件分进行中和已结束。进行中按截稿日升序，每页 20 条；已结束按实际结束时间倒序，每页 50 条。旧订单没有结束时间时，以原截稿日排序，不捏造完成时间。重新打开已结束稿件后会重新记录下次结束时间。
- 稿件模板按平台分组并缩小卡片。平台填色面积扩大；整体布局、导航、字体和黑白基调保持原样。平台选择的颜色会保留。
- 新建稿件和模板默认不显示图片。勾选“添加并显示图片”后可上传。取消勾选只隐藏图片，不删除已经保存的参考图。
- 单主列表与新建稿件的单主下拉框共用排序：有创建/导入时间的单主按该时间倒序，同一导入批次按最近合作倒序；历史单主缺少创建时间时按最近稿件合作时间倒序，再按原记录顺序倒序。导入不会删除原数据。
- 价目表支持图片、名称、价格、说明、卡片及文字颜色、底图、背景颜色、列数、画布宽高参数、条目拖拽排列。条目模板与整张价目表分别保存，模板拖入后为独立副本；修改模板不覆盖已加入的条目。可复制 PNG 图片到剪贴板或下载 JPG。
- 快捷回复只包含文字及稿件模板关联。可勾选添加订单回复、首页介绍、评价模板、回答模板分组，也可自建多层文字分组。每条回复可关联零个、一个或多个稿件模板，并可搜索、筛选、编辑、删除、复制。删除文字分组时，其文字及子分组移到上级；删除稿件模板时解除文字关联并保留文字。

## 保存与兼容

价目条目、价目表、文字分组、文字模板存入现有 SQLite 的 `desktop_records`；关联由 `desktop_edges` 外键维护。图片和底图沿用内容摘要命名的私有文件目录，不存入浏览器缓存。继续使用现有事务、版本冲突检测和备份恢复接口。

SQLite 格式升到 4：从 2/3 版迁移前先创建完整备份，事务内添加迁移记录、验证关联，失败回滚。结构版本升高使旧程序拒绝打开新格式，避免旧程序忽略新增组件记录。2/3/4 版备份可读取；JSON 备份合并为新编号并重连文字分组和稿件模板关联。

本次没有让新版打开正式数据库。升级到正式使用前，仍需保留原完整备份；不要拿旧版安装程序覆盖打开新版数据目录。
